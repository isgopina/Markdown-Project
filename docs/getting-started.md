## Overview

WhatsApp is a messaging application owned by Meta Platforms that connects people around the world.

This guide describes how to set up WhatsApp for the first time and explore the home screen.

WhatsApp uses Wi-Fi or cellular data instead of SMS. WhatsApp uses your phone number to connect you with your contacts. Every message and call is end-to-end encrypted.
Key features:

- Free messaging and voice or video calls
- Photo, video, and status sharing
- Group chats and communities
## Prerequisites

- You need a working smartphone that is either Android or iOS.
- You need a valid phone number that can receive an SMS or a phone call.
- You need to have an internet connection (Wi-Fi or mobile data).
## Getting Started

![](/images/user%20guide%20screenshot.png)
After you install WhatsApp, complete the following setup steps.


1. Download and install WhatsApp.
2. Open WhatsApp.
3. Agree to the terms and conditions.
4. Enter and verify your phone number.
5. Allow the app to access your contacts.
6. Set up your profile: Type your name.
7. Optional: Add a profile picture if you want.
8. Tap **Next** or **Done** to finish.

You can now send a message, make a phone call, or post a status update.
